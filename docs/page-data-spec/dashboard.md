## 2. 이 문서의 목적

백엔드가 없어 `frontend.rule.md` **A3**(API 갭을 `docs/api-gaps.md`에 등록)이 성립하지 않는다. 대신 **화면이 무엇을 필요로 하는지**를 여기 남긴다. 백엔드 착수 시 이 문서가 계약 설계의 입력이 된다.

현재 이 데이터는 전부 `src/entities/<slice>/api/fixtures.ts`가 생성한다. 원천은 `src/shared/config/demo-scenario.ts` 한 곳이다.

## 3. 패널별 요구 데이터

### 3.1 사업장 목록 · 지도 (FR-31~33)

| 필드 | 타입 | 근거 |
|---|---|---|
| `id` / `name` / `industry` / `region` | string | 업종 5종은 사업계획서 p.37 |
| `coordinates` | `[lat, lng]` | **원문 없음.** 지도 표시를 위해 신설. 시·군 중심 근사값 |
| `anomalyScore` | `number \| null` | 0~100 (p.64). 통신 두절이면 **null** |
| `status` | 4등급 \| null | 잠정값(INC-01·03·04) |
| `online` | boolean | ECP 통신 상태 |
| `lastSyncIso` | ISO8601 | 마지막 수신 시각 |
| `spark` | `(number \| null)[]` | 카드 추이. 이상 점수 계열의 다운샘플 |
| `dataThroughput` / `uptime` | number | 목표 ≥98% / ≥95% (p.3, p.119) |

> **미확정**: 사업장 위치, 사업장-그룹-테넌트 계층(TBD-08·13).

### 3.2 실시간 계측 (FR-01·FR-05)

- 수질 8항목 + 설비 3항목. 단위·측정범위·정확도는 사업계획서 p.55.
- 5분 간격 × 24시간 = 288 표본. 수집 주기 1~10분(p.30·p.48) 범위 안.
- **결측은 `null`.** 0으로 채우면 배출량 급감으로 오독된다(E4).

> **미확정**: 표시 소수 자릿수(원문 없음 → `PROVISIONAL_DECIMALS`), EC 단위가 계측 사양 μS/cm와 성능지표 mS/cm로 어긋남.

### 3.3 이상 점수 (FR-07·FR-08·FR-09)

| 필드 | 타입 | 근거 |
|---|---|---|
| `score` | `number \| null` | 0~100 정규화 (p.64) |
| `level` | 4등급 \| null | 잠정값 |
| `computedAtIso` / `windowLabel` / `modelLabel` | string | **E3 — 산출 시각·대상 기간을 값과 함께 노출** |
| `contributions` | `{label, weight, direction}[]` | Feature Attribution (p.64) |

> **미확정**: 점수→등급 경계(TBD-02, 현재 `0–49/50–69/70–79/80–100` 추천값), 등급↔알람 우선순위 대응(TBD-21).

### 3.4 예측 (FR-10·FR-11·FR-15)

- 대상 TOC·TN·TP (p.68), 지평 1~6시간 (p.32·p.65).
- 실측/예측/신뢰구간 하한·상한을 **한 시간축**에 담되 실측 구간과 예측 구간은 서로 `null`로 구분.
- 경향 3분류 + R².

> **미확정**: 신뢰구간의 신뢰수준(%), 출력이 수치 예측인지 경향성 분류인지(INC-05).

### 3.5 알람 (FR-27~30)

- 우선순위 3종(긴급/주의/정보), 조건 4종, 상태 3종, `siteId`.
- 목록은 전 사업장이며 선택 사업장을 상단 정렬.

> **미확정**: 임계값 수치(TBD-01), 우선순위 판정 기준(TBD-03), 확인·에스컬레이션 절차(TBD-05·09), 채널 확정(TBD-10).

### 3.6 설비 예지보전 (FR-13·FR-19·FR-20)

- 고장 확률 0~100% (p.66), 잔여 수명(RUL), MPI, 상태 등급.

> **미확정**: MPI 산정식·값 범위·단위(TBD-22), RUL 단위.

## 4. 백엔드 착수 시 확인할 것

1. **결측 표현** — 화면은 `null`을 기대한다. `0`이나 `-999` 같은 센티널로 내려오면 E4를 지킬 수 없다.
2. **AI 산출값의 메타데이터** — 값만 주면 안 된다. 산출 시각·대상 기간·모델이 함께 와야 E3를 지킨다.
3. **등급 판정 위치** — 점수→등급 변환을 서버가 할지 클라이언트가 할지. 현재는 클라이언트(`toStatusLevel`).
4. **권한** — 현재 역할 분기는 **인가가 아니라 시연 표시**다(E6 예외). 서버 응답 권한으로 교체해야 한다.
5. **시간대** — 현재 포맷터는 시연 데이터가 KST 벽시계인 전제에 기대고 있다. 실제 타임스탬프가 들어오면 시간대 변환을 제대로 해야 한다.
