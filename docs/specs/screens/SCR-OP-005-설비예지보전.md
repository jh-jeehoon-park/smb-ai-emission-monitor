## 6. 상태와 예외

| 상황 | 표시 |
|---|---|
| 통신 두절 사업장 | 요약 카드가 `—` + "설비 수신값 없음" + 복구 시 로컬 버퍼 일괄 전송 안내. 상세표는 비운다 |
| 전 사업장 순위 | 두절 사업장 제외 + 제외 사실을 머리글에 표기 |
| 관련 알람 0건 | 빈 목록 |

**통신 두절 시 설비 지표를 보여주지 않는 이유** — 계측·이상 점수·예측이 전부 결측인데 설비만 멀쩡한 숫자를 띄우면 한 화면이 서로 다른 말을 한다(**E3·R19**).

## 7. 설계 근거

**정렬 기준을 셋 둔 이유는 관점이 셋이기 때문이다** `[설계: MPI=지금 손봐야 할 것, 고장 확률=곧 멈출 것, 잔여 수명=교체 계획이 필요한 것]`.

**전 사업장 우선순위를 따로 둔다** `[설계: 정비 인력은 사업장을 가로질러 배치된다. 한 사업장 안에서만 줄을 세우면 어느 사업장부터 갈지 답이 나오지 않는다]`. FR-21(유지관리 우선순위 자동 추천)이 요구하는 것이 이것이다.

**MPI 산식을 세우지 않는다** `[TBD-22]` `[설계: 원문에 산정식·범위·단위가 없다. 그럴듯한 식을 만들면 확정된 값처럼 읽힌다]`. 0~100 상대 지수로만 표시하고 화면에도 그렇게 적는다.

**고장 확률에 막대를 곁들인다** `[설계: 숫자만으로는 4대의 차이가 눈에 들어오지 않는다]`. 같은 축의 막대라 길이 비교가 곧 값 비교다.

**설비 수명 증가 목표를 화면에 넣지 않았다** `[INC-18: 같은 페이지에서 ≥15%와 ≥10%로 갈린다]`.
