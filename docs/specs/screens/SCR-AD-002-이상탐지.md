```

├────────────────────────────────────────┤  산출 시각               │
│ 사업장별 이상 점수    점수 높은 순      │                          │
│ ┌────────────────────────────────────┐ │  주요 기여 변수 · XAI    │
│ │ 1 구미 염색 2공장  ∿∿∿   88 위험   │ │  TOC ▲ ────────  34%    │
```

## 4. 요구 데이터

### 4.1 이상 점수 계열 (`AnomalyPoint[]`)

| 데이터 | 타입 | 단위 | 근거 |
|---|---|---|---|
| `t` | ISO8601 | KST | `[설계]` 계측과 같은 시간축 |
| `score` | number \| null | 점 | 0~100 정규화 `[원문 p.64]`. 결측·두절 시 `null` |

288 표본(5분 × 24시간). 계측과 **같은 결측 판정**을 쓴다 `[설계: 한 화면에서 계측은 끊기고 점수는 이어지면 모순이 된다]`.

### 4.2 이상 탐지 결과 (`AnomalySummary`)

| 데이터 | 타입 | 단위 | 근거 |
|---|---|---|---|
| `score` | number \| null | 점 | 0~100 `[원문 p.64]` |
| `level` | `normal`\|`caution`\|`warning`\|`critical` \| null | — | `[INC-01·03·04]` 잠정 4단계 · 경계 `[TBD-02]` |
| `online` | boolean | — | `[설계]` 통신 상태 |
| `computedAtIso` | ISO8601 | KST | **E3** |
| `windowLabel` | string | — | 대상 기간 (예: 최근 1시간 다변량 패턴) **E3** |
| `modelLabel` | string | — | AutoEncoder 복원오차 기반 `[원문 p.64]` **E3** |
| `contributions[].label` | string | — | 기여 변수명 `[원문 p.64]` |
| `contributions[].weight` | number | 0~1 | Feature Attribution 기여도 `[원문 p.64]` |
| `contributions[].direction` | `up`\|`down` | — | `[설계]` 상승/하강 기여 구분 |

### 4.3 사업장별 순위

| 데이터 | 출처 |
|---|---|
| 사업장 최신 점수·등급 | `Site.anomalyScore` · `Site.status` |
| 추이 스파크라인 | `[파생: buildAnomalyScores(siteId) 다운샘플 40점]` |

`condition === 'anomaly'`인 알람만 `[설계: 이 화면의 관심은 이상 탐지 조건이다]`.

## 6. 상태와 예외

| 상황 | 표시 |
|---|---|
| 통신 두절 사업장 | 결과 패널이 `—` + "산출값 없음" + 마지막 수신 시각(**E3**) |
| 구간 결측 | 타임라인이 끊기고 해당 구간에 음영(**E4**) |
| 순위의 두절 사업장 | **점수를 0으로 내리지 않고** 목록 끝에 `수신 없음`(**E4**) |
| 관련 알람 0건 | 빈 목록. 개수를 머리글에 표기 |

## 7. 설계 근거

**사업장별 순위를 넣은 이유** `[설계: 한 사업장만 보면 그 점수가 높은 건지 알 수 없다. 통합 관제의 판단은 늘 비교다]`. 대시보드에는 없던 요소다.

**구간 범례를 차트 머리글에 둔다** `[설계: 4구간 경계가 잠정값(TBD-02)이라 값을 읽는 사람이 경계를 함께 봐야 한다]`. 같은 범례를 통합 관제에서도 쓰며 구현은 한 곳이다(`anomaly-band-legend.tsx`) — 두 곳에 두면 구간이 갈린다.

**기여 변수에 방향(▲▼)을 함께 낸다** `[설계: 기여도만으로는 그 변수가 점수를 올렸는지 내렸는지 알 수 없다]`.

**색만으로 등급을 전달하지 않는다** — 색 + 글리프(●◆▲■) + 라벨을 함께 쓴다(REQ-NF-008).
