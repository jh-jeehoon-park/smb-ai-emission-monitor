## 2. 이 문서의 목적과 원천

**한 행이 한 필드다.** 데이터 정의서 xlsx로 그대로 옮겨진다.

원천은 코드다. 문서가 코드를 앞서지 않는다.

| 무엇 | 어디 |
|---|---|
| 필드·타입 | [`src/entities/<slice>/model/types.ts`](../../src/entities/) 7개 슬라이스 |
| 계측 항목의 단위·범위·정확도·자릿수 | [`src/shared/config/measurement.ts`](../../src/shared/config/measurement.ts) |
| 상태 등급·이상 점수 구간·**모든 임시값**(계측 외 표시 자릿수 포함) | [`src/shared/config/provisional.ts`](../../src/shared/config/provisional.ts) |
| 시연 데이터 원천 | [`src/shared/config/demo-scenario.ts`](../../src/shared/config/demo-scenario.ts) |

현재 데이터는 전량 fixture다. 백엔드가 생기면 이 표가 **응답 계약 설계의 입력**이 된다.

### 2.1 표 읽는 법

| 열 | 뜻 |
|---|---|
| 데이터 그룹 | 도메인 슬라이스 |
| 타입 | TypeScript 기준. `\| null`은 **결측 가능**을 뜻한다 |
| 계산식/로직 | 파생값의 산출 방법. 원본이면 `—` |
| 출처·근거 | [README §3](README.md) 근거 표기 규약 |
| UI 표출 | `Y` 화면에 보임 / `N` 내부 계산용 |

**`\| null`은 장식이 아니다.** 결측을 `0`이나 센티널로 대체하면 화면이 거짓을 말한다(**E4**).

### 2.2 커버리지

타입 정의의 필드가 이 문서에 빠짐없이 있는지는 세어서 확인한다.

아래 `선언`은 `entities/<slice>/model/types.ts`의 필드 선언 수이며 **`npm run verify:docs`가 이 표와 대조한다.** 숫자를 고칠 때는 표만 고치지 말고 검사를 다시 돌린다.

| 슬라이스 | 선언 | 문서에 없는 선언 | 절 |
|---|---|---|---|
| site | 16 | 없음 | §3 |
| measurement | 12 | 없음 (파생 통계 7종은 §4.2에 별도) | §4 |
| anomaly | 12 | `contributions` 배열 컨테이너 1 | §5 |
| prediction | 26 | 라벨맵 3 · 배열 컨테이너 2(`points`·`trends`) | §6 |
| water-analysis | 20 | 배열 컨테이너 1(`samples`) · 값 맵 1(`values`) | §6.2 |
| equipment | 7 | 없음 | §7 |
| alarm | 19 | 라벨맵 10 → §8.1 라벨 사전이 대신한다 | §8 |
| optimization | 17 | 없음 (비용 절감 파생 11종은 §9.2에 별도) | §9 |
| process | 12 | 없음 | §10.3 |
| user | 5 | 없음 (`Role`·`RoleScope`는 필드가 아니라 타입 별칭이라 세지 않는다) | §10.1 |

필드를 추가하면 **같은 작업에서** 이 문서에도 행을 더한다. 빠뜨리면 검사 6이 잡는다.

**이 표는 코드에서 떨어진 것만 잡는다.** 원문에서 떨어진 것은 잡지 못한다 — 타입에 없는 데이터는 셀 수가 없기 때문이다. 그쪽은 §4.1이 담당한다.

| 대조 축 | 무엇을 잡는가 | 어디 |
|---|---|---|
| 코드 → 문서 | 타입에 필드를 더하고 문서를 안 고친 것 | §2.2 이 표 · `verify:docs` 검사 6 |
| **원문 → 문서** | **원문이 요구했는데 화면에 없는 것** | **§4.1** · 수동 대조(§3 규칙 6) |

리본(SCR-AD-003)은 이 세 상태를 **네 행에 같은 시간축으로** 얹는다 — 축이 어긋나면 세로로 훑을 때 서로 다른 시각을 비교하게 된다.

**세 상태를 가른다** `[설계]`: 방류 중(`true`) · 방류 없음(`false`) · **모름(`null`, 통신 두절)**. 두절을 `false`로 적으면 "방류가 없었다"는 사실 주장이 되어 결측을 0으로 그리는 것과 같은 거짓말이 된다(**E4**).
