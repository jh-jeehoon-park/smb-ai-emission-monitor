## 2. 이 문서의 지위 — 원문이 아니고, 아직 화면도 아니다

**원문이 아니다.** 주관사(HSK)가 2026-09-11에 수행한 **현장조사 결과**이며, 근거 위계상 원문 2건(사업계획서·발표자료)과 다른 갈래다(`deliverable-xlsx.rule.md` §4). 원문이 계획을 적었다면 이 문서는 **실제로 가 본 결과**를 적는다 — 둘이 어긋나면 그 사실을 §8에 남긴다.

**화면과 fixture에 반영하지 않는다** `[사용자 결정 2026-09-28]`.

> *"학습된 파일의 사업소는 **실 데이터 연동 전까지는 내용만 참고**할 것"*

시연 사업장 10개소(`SITE_SCENARIOS`)는 그대로 두고, 이 5개소는 **설계 판단의 참고 자료**로만 쓴다. 실 데이터 연동이 시작될 때 이 문서가 교체의 근거가 된다.

**1차 선정 5개소다** `[사용자 결정 2026-09-28]`. 원문의 실증 10개소 목표 `[원문 p.29]`는 유지되고, 나머지 5개소는 추후 선정된다. 파일명의 「후보지 선정」과 달리 **이 5개소는 선정 완료**다.

## 5. 계측 구성

### 5.1 측정 지점은 «최종 방류수» 한 곳이다

5개소 전부 같다 — **최종 방류수조에서 처리수를 취수 → 별도 측정수조로 이송 → 센서 침적**. 공정 단계마다 달지 않고, 유입에도 달지 않는다.

| | 설치유형 | 설치 위치 | 취수 |
|---|---|---|---|
| 에버 | 옥외형 판넬 + 별도 측정수조 | 화장실 인근 외부공간 | 방류수조에서 펌핑 |
| ㈜배상면주가 | 측정수조 + 일반·광학 계측부 + TN·TP 분석기부 + 전장·통신부(**D타입**) | 최종 방류수조 인접 기존 시설 내 | 최종 방류수조 |
| 진선식품 | **외부 컨테이너형** | 폐수처리동 외부 측면 | 최종 여과·방류조 |
| 칠갑농산 | **컨테이너형** | 폐수처리동 외부 화장실 옆 | 최종 방류수조(계단 하부) |
| 대호특수강 | 실내 판넬형 | 방류계통에서 **약 27m 떨어진 실내** | 모래여과·파샬플룸 이후 방류계통 |

**대호특수강의 27m가 제약이다** — 고저차·펌프양정·체류시간·침전·막힘·동절기 동결을 함께 봐야 한다. 같은 공간에 대형 인버터 등 전기설비가 있어 **구획과 누수방지**도 필요하다.

### 5.2 수질 측정항목 — 공통 7종 + TN·TP

**공통 7종: pH · DO · EC · 탁도 · 수온 · TOC · NO₃-N**

| | 항목 수 | TN | TP |
|---|---|---|---|
| 에버 | 7 | — | — |
| ㈜배상면주가 | 9 | ○ | ○ |
| 진선식품 | 8 | ○ | — |
| 칠갑농산 | 9 | ○ | ○ |
| 대호특수강 | 9 + 유량 | ○ | ○ |

**TN·TP를 분석기로 실측한다.** 대호특수강은 그 용도를 *"수질항목 간 상관성 분석과 **Soft Sensing 적용성 검토**"* 로 적었다 — 실측이 **정답지**이고 AI 추정이 그것과 대조되는 구조다.

**색도가 다섯 곳 어디에도 없다** → §9 확인 대상.

**8종은 우리 시스템의 필수 항목이되, 사업장별 차이가 있을 수 있다** `[사용자 확인 2026-09-28]`. 현장조사가 그 차이를 실제로 보여 준다 — **7종 · 8종 · 9종**으로 갈리고, 한쪽은 색도가 빠지고 다른 쪽은 TN·TP가 더 붙는다. **지금 화면은 전 사업장이 같은 8종이라고 가정한다**(`WATER_SERIES_CODES` 하나를 열 곳에 쓴다) — 실 데이터 연동 시 **사업장마다 보유 항목이 다른 경우**를 화면이 어떻게 다룰지가 함께 정해져야 한다. 이미 쓰는 어휘가 있다: 채널이 없는 계열은 `미수신`, 우리가 만든 값은 `시연값` 배지다([계측 서버 연동](../integration/README.md) §8.0) — **«그 사업장에는 애초에 없는 항목»은 그 셋 중 어디에도 없다.**

## 6. 유량·전력·운전신호 — **수집 범위를 우리가 정한다**

### 6.1 유량계

| | 기존 | 개선 방안 |
|---|---|---|
| 에버 | **수동식 수도미터** — 실시간 출력 불가 | 통신 가능한 전자식 **신규 설치** |
| ㈜배상면주가 | 개수로형 전자식 | 출력단자·4–20mA/RS-485 확인 후 활용, 안 되면 교체 |
| 진선식품 | **KEC-101FI** 개수로형 전자식 | 통신출력 확인 필요. 불가 시 변환기·유량계 교체 |
| 칠갑농산 | 파샬플룸 + 전자식(제조사·모델 미확인) | 기존 연계가 아니라 **실증용 전자식을 별도 설치** |
| 대호특수강 | **KEC-101FI** Open Channel, 누적유량 표시 | 기존 활용 우선. 신뢰성 부족 시에만 교체 |

**유량은 방류 한 지점이다.** 유입유량계는 진선식품 공정 설명에만 나오고, 계측 대상으로 잡힌 것은 **방류유량**이다.

## 7. AI 활용 — 한 곳만 구체적이다

네 곳은 *"JH솔루션 검토 후 확정"* 이고, **대호특수강만 용도를 적었다**.

> *"수질·유량·설비운전 데이터를 연계하여 **처리수질 이상징후 탐지**, **수질변화 예측**, 공정 운전상태 분석 및 **주요 영향인자 도출**에 활용함. TN·TP 실측데이터는 수질항목 간 상관성 분석과 Soft Sensing 적용성 검토에 활용함."*

**수집 한계도 사업장이 스스로 말한다** — 이쪽이 화면 설계에 더 직접적이다.

| | 한계 |
|---|---|
| 에버 | 처리량이 적고 **방류가 간헐적**이라 수질·유량이 연속으로 발생하지 않을 수 있음. 반입 폐수의 성상·시점도 일정하지 않음 |
| ㈜배상면주가 | 제조품목·생산량에 따라 알코올·유기물 부하가 달라짐 |
| 진선식품 | 생산량·세척수에 따라 유입량·부하 변동 |
| 칠갑농산 | 평균 15~20톤·일로 적고, **생산 감소·방류 중단 시 데이터 공백** |
| 대호특수강 | 설비가 다양해 전부 계측하면 범위·비용 증가. 신호 외부출력 여부 미확인 |

**결측이 예외가 아니라 상시 상태다.** 결측을 0으로 그리지 않는다(**E4**)는 규칙이 실증에서 화면의 기본 동작이 된다.
