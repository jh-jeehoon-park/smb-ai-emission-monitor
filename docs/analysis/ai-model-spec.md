### 2.1 폐수처리 공정 데이터의 4대 특성

원문은 폐수처리 공정 데이터를 다항목성·시계열성·비선형성·설비 의존성 4가지 특성으로 규정하고, 각 특성에 대응하는 AI 기법을 매칭한다 (사업계획서 p.62, p.63).

| 특성 | 원문 정의 | 대응 AI 접근 | 출처 |
|------|-----------|--------------|------|
| 다항목성(Multivariate Characteristics) | TOC, TN, TP, pH, DO, SS, EC, 탁도, 유량, 설비 전류·전력 등 10개 이상 항목이 동시 변화하며 항목 간 상호작용 존재 | AutoEncoder, CNN 등 다변량 데이터 복합 패턴 학습 모델 적용 | 사업계획서 p.62 |
| 시계열성(Time-Series Characteristics) | 시간 의존적 변화 패턴, 자기상관 구조(autocorrelation), 체류시간(HRT)·생물학적 반응 시간에 의한 지연 응답(time-lag response), 계절성(seasonality) | LSTM 기반 시계열 예측 모델 적용(장기 의존성 학습 가능) | 사업계획서 p.62 |
| 비선형성(Non-linearity) | 유입 부하 변동, 계절 영향, 온도 변화, 미생물 활성도, 공정 조건 변화에 따라 비선형 거동 | LSTM·CNN은 비선형 활성화 함수(ReLU, tanh 등)로 학습, RandomForest는 결정 트리 기반 비선형 경계(decision boundary) 생성 | 사업계획서 p.62 |
| 설비 의존성(Equipment Dependency) | 처리 설비(펌프, 폭기장치, 약품주입펌프 등)의 운전 상태가 수질에 직접적 영향 | RandomForest, XMARL-PPO 등으로 설비 운전 데이터와 수질 데이터 통합 학습 | 사업계획서 p.62, p.63 |

#### 2.1.1 특성별 원문 인과 사례

| 특성 | 원문에 명시된 인과 관계 | 출처 |
|------|------------------------|------|
| 다항목성 | 유기물(TOC) 증가 → 미생물 성장 증가 → 영양염류(TN, TP) 소비 증가 또는 방출 증가 | 사업계획서 p.24, p.62 |
| 다항목성 | DO 감소 → 질산화(nitrification) 저해 → TN 증가 | 사업계획서 p.24, p.62 |
| 다항목성 | pH 변화 → 인(P) 용출 또는 침전 → TP 변화 | 사업계획서 p.24, p.62 |
| 다항목성 | TN 증가 → 질산화 반응 증가 → pH 저하, DO 소비 증가 | 사업계획서 p.22 |
| 다항목성 | 유기물(TOC) 증가 → 혐기성 조건 발생 → 인(TP) 방출 증가 | 사업계획서 p.21 |
| 시계열성 | t-1 시점 TOC 상승 → t 시점 미생물 활성도 변화 → t+1 시점 TN 변화 | 사업계획서 p.62 |
| 시계열성 | 유입 부하 증가 → 2~4시간 후 TOC 상승 → 6~12시간 후 TN 변화 | 사업계획서 p.24 |
| 시계열성 | 계절성 — 수온 변화에 따른 미생물 활성도 변화, 여름철 DO 저하 | 사업계획서 p.62 |
| 비선형성 | TOC 50mg/L 증가 시, DO 7mg/L일 때 TN 증가 5mg/L / DO 3mg/L일 때 TN 증가 15mg/L | 사업계획서 p.24, p.62 |
| 설비 의존성 | 폭기량 감소 → DO 저하 → 질산화 저해 → TN 증가 | 사업계획서 p.24, p.62 |
| 설비 의존성 | 유량 감소 → 체류시간 증가 → TOC 처리 효율 향상 또는 TP 방출 증가 | 사업계획서 p.24, p.62 |
| 설비 의존성 | 약품 주입량 감소 → 응집 효율 저하 → SS, TP 증가 | 사업계획서 p.24, p.63 |

> 단일 변수 분석방식의 한계로 "개별 항목만 보면 정상이나, 항목 간 관계 이탈 시 이상 징후"가 명시된다 (사업계획서 p.62). 구체 예시는 "TOC 정상 + EC 정상 상태에서도 TOC–EC 상관관계 이탈은 처리 공정 이상의 전조 신호일 수 있으나 단일 임계값 방식으로는 탐지 불가"다 (사업계획서 p.22).

### 2.2 기존 통계 모델의 한계와 AI 모델의 우위

#### 2.2.1 기존 통계 모델의 한계 (적용 원리 기준)

| 분석 방법 | 적용 원리 | 한계점 | 폐수처리 적용 시 문제 |
|-----------|-----------|--------|------------------------|
| 다중회귀분석 | Y=β₀+β₁X₁+β₂X₂+...+ε | 선형관계, 독립변수 간 다중공선성 문제 | TOC-EC-탁도 간 비선형 관계 반영 불가 |
| 시계열분석(ARIMA) | 과거 값 기반 미래 예측 | 단일 변수만 분석, 외부 변수 반영 한계 | 설비 운전 데이터 반영 불가 |
| 상관분석 | Pearson 상관계수 | 2변수 간 선형관계만 측정 | 다변량 복합 패턴 분석 불가 |
| 임계값 기반 알람 | If X > threshold → alarm | 단일항목 기준, 복합 이상 미탐지 | pH 정상 + EC 정상이지만 pH-EC 관계 이탈 시 미탐지 |

(사업계획서 p.61)

#### 2.2.2 기존 통계 모델의 한계 (적용 사례 기준)

| 분석 방법 | 적용 사례 | 한계 |
|-----------|-----------|------|
| 단순 상관분석 | TOC–EC 상관계수 산정 | 비선형 관계 반영 불가, 다변량 분석 불가 |
| 이동 평균 | 7일 이동 평균 추세 분석 | 돌발성 변동 탐지 불가, 미래 예측 불가 |
| 임계값 알람 | TOC > 100mg/L 알람 | 복합 이상 패턴 탐지 불가, 오탐지율 높음 |
| 다중 회귀 분석 | TOC = a×EC + b×탁도 + c | 비선형성 및 시간 지연 효과 반영 불가 |

(사업계획서 p.24)

> 기존 IoT 기반 모니터링에 적용된 통계적 방법은 단순 상관분석(Pearson), 이동 평균, 임계값 알람 3종이며, 한계는 비선형 수질 변화 반영 불가·TOC/TN/TP 복합 이상 패턴 탐지 불가·시간 지연 효과 반영 불가로 정리된다 (사업계획서 p.22).

#### 2.2.3 AI 모델의 우위 비교표

| AI 모델 | 적용 원리 | 우위점 | 폐수처리 적용 효과 |
|---------|-----------|--------|--------------------|
| AutoEncoder | 정상 패턴 학습 → 복원 오차 기반 이상 탐지 | 비지도 학습, 다변량 복합 패턴 자동 탐지 | TOC–EC–탁도 복합 이상 패턴 탐지 정확도 30%↑ |
| LSTM+CNN | 시간 패턴(LSTM) + 공간 패턴(CNN) | 다변량 센서 데이터 공간·시간적 패턴 동시 학습 | 1~6시간 사전 예측, MAE 10~15% 수준 |
| RandomForest | 결정 트리 앙상블 | 비선형 관계 학습, 변수 중요도 분석 | 설비–수질 관계 분석, 주요 영향 인자 식별 |
| XMARL-PPO | 다중 에이전트 강화학습 | 설비 수명주기 고려 최적화, XAI 적용 | 에너지 효율 10%↑, 설비 수명 연장 |

(사업계획서 p.61)

동일 취지의 표가 사업계획서 p.25에도 있으며 기법 명칭과 서술이 다르다.

| AI 모델 | 적용 기법 (p.25) | 우위 (p.25) |
|---------|------------------|-------------|
| AutoEncoder | 비지도 학습 기반 이상 탐지 | 다변량 복합 이상 패턴 자동 탐지, 정상 데이터만으로 학습 가능 |
| LSTM | 시계열 간접 추정 | 시간 지연 효과 반영, 미래 1~6시간 간접 추정 가능 |
| RandomForest | 비선형 회귀 | 비선형 관계 학습을 통한 설비 예지보전 |
| XMARL-PPO | 강화학습 기반 최적화 | 설비 수명주기 고려 에너지 최적화 |

(사업계획서 p.25)

> ⚠ 모순 — 예측 모델 구성: p.60·p.61·p.63은 예측 모델을 **LSTM+CNN 다단연계**로 기술하나, p.25·p.64·p.65·p.68의 최종 모델 구성에는 **CNN이 빠지고 LSTM 단독**으로 기술된다. CNN의 최종 포함 여부는 확정되지 않았다. 상세는 [source-inconsistencies.md](../requirements/source-inconsistencies.md) 참조.

> 원문 총평: "통계학적 모델로는 비선형 거동 분석에 한계가 있으며, 인공지능 모델 적용 시 예측 정확도 및 최적화 성능이 향상됨" (사업계획서 p.61), "AI 기반 분석은 다변량·비선형·시계열 통합 분석 구조로 기존 통계 방식 대비 이상 탐지-추정-최적화를 통합 수행 가능" (사업계획서 p.25).

### 2.3 모델 선정 5단계 절차

원문 제목은 "국내 환경 분야 선행 R&D 기반 AI 모델 선정 체계"다 (사업계획서 p.59).

| 단계 | 명칭 | 원문 내용 | 출처 |
|------|------|-----------|------|
| 단계 1 | 데이터 특성 분석 | 폐수처리 공정 데이터는 시간 의존성(temporal dependency)이 강한 시계열 데이터임. TOC, TN, TP는 과거 데이터가 미래값에 영향을 미치는 자기상관 구조(autocorrelation structure) 보유. 시계열 데이터 분석에 유리한 LSTM을 기본으로 두고 CNN 등과의 다단연계를 통해 수처리 및 신재생에너지 생산공정별 최적 딥러닝 기법을 발굴·활용 | 사업계획서 p.59 |
| 단계 2 | 다변량 패턴 학습 필요성 | 폐수처리 공정은 pH, EC, 탁도, DO, 수온, TOC, TN, TP 등 8개 이상 항목이 동시 변화하며 항목 간 상호작용 존재. 단일항목 분석으로는 복합 이상 패턴(compound anomaly pattern) 탐지 불가. LSTM 단독 사용의 한계 극복을 위해 CNN과 다단연계하여 다변량 센서 데이터의 공간적 상관관계를 학습 | 사업계획서 p.59 |
| 단계 3 | 블랙박스 문제 해결 | 운영자가 공정 성능 예측 결과를 이해하고 신뢰성을 높일 수 있는 XAI 모델 개발. 수처리 현장 운영자는 AI 예측 결과를 이해하고 신뢰할 수 있어야 실제 의사결정에 활용 가능. XAI(설명 가능한 AI) 기법 필수 적용 — SHAP(SHapley Additive exPlanations), Attribution 등 | 사업계획서 p.59, p.60 |
| 단계 4 | 통계 모델과 비교 검증 | 인공지능 모델 구축 초기에 통계학적 모델과의 성능 비교·평가가 이루어질 수 있음. AI 모델 구축 초기 단계에서 다중회귀분석, 시계열 분석(ARIMA) 등 전통적 통계학적 모델과 성능 비교를 수행하여 AI 적용 타당성을 객관적으로 검증 | 사업계획서 p.60 |
| 단계 5 | 강화학습 결합 | 딥러닝 모델과 강화학습의 결합 또는 비교 분석을 통한 에너지-환경 공정 최적화 검증. 예측 모델(LSTM, CNN)과 최적화 모델(강화학습)을 결합하여 설비 운영 최적화 수행. 고려대학교 XMARL-PPO 알고리즘 "AI를 활용한 펌프 및 송풍기 수명주기 기반 에너지 소비효율 최적화" 검증 | 사업계획서 p.60 |

### 2.4 선행 연구·학술 근거

| 구분 | 출처·과제 | 원문 내용 | 출처 |
|------|-----------|-----------|------|
| 국내 R&D | 환경부 차세대 초순수 생산공정 R&D (2026~2030) | LSTM+CNN 다단연계 딥러닝 기법 적용 / XAI 모델 개발을 통한 운영자 신뢰도 향상 / 통계학적 모델 대비 AI 모델 우위성 검증 / 딥러닝 모델과 강화학습 결합을 통한 에너지 절감 | 사업계획서 p.26, p.63 |
| 국내 R&D | 환경부 고농도 염배수 생태독성 평가 시스템 R&D (2026~2030) | 설명 가능한 AI(XAI) 기술을 통한 성분별 독성 기여도(Attribution) 정량 분석 / SVM, RandomForest 기반 가상 생태독성(Virtual WET) 예측 | 사업계획서 p.26, p.63 |
| 특허 동향 | AI 기반 실시간 독성 예측·성분 기여도 분석 | 관련 특허 출원이 2020년 대비 약 180% 증가 | 사업계획서 p.26, p.63 |
| 특허 동향 | 수질 모니터링 분야 AI 특허 키워드 | Machine Learning, Deep Learning, Artificial Intelligence, Predictive Modeling, Virtual Sensing | 사업계획서 p.63 |
| 국제 학술 | 하수처리장 유출수 수질 예측 (Journal of Environmental Management, 2022) | LSTM 기반 모델, MAE 10~15% 수준 달성 | 사업계획서 p.63 |

| 국제 학술 | 폐수처리 공정 이상 탐지 (Environmental Science & Technology, 2023) | AutoEncoder 기반 다변량 이상 탐지, 정확도 85~95% | 사업계획서 p.63 |

AI 모델 적용 타당성 결론은 3가지로 정리된다 (사업계획서 p.27).

1. 폐수처리 공정은 시계열 데이터 분석에 유리한 LSTM을 기본으로 CNN과의 다단연계를 통한 비선형 패턴 학습이 효과적임(환경부 R&D 검증).
2. 블랙박스 기반 머신러닝 한계 극복을 위해 설명 가능한 AI(XAI) 모델 개발이 필요하며, 이는 운영자의 의사결정 신뢰도를 향상시킴.
3. 통계학적 모델로는 다변량 비선형 거동 분석에 한계가 있으며, AI 모델 적용 시 추정 정확도 및 최적화 성능이 향상됨(선행 연구 검증).

> ⚠ 모순 — MAE 10~15%의 성격: 사업계획서 p.61에서는 "LSTM+CNN … 1~6시간 사전 예측, MAE 10~15% 수준"이 자사 적용 효과처럼 기술되고, p.63에서는 동일 수치가 국제 학술 인용치로 기술된다. 자사 목표치인지 인용치인지 원문상 구분되지 않는다. 상세는 [source-inconsistencies.md](../requirements/source-inconsistencies.md) 참조.

> 원문 기재 그대로 옮긴 사항: 두 환경부 R&D 과제 기간이 모두 "2026~2030"으로 기재되어 있다 (사업계획서 p.26, p.63).

## 3. 모델 구성 개요

### 3.1 구성 원칙

AI 분석 엔진은 **4개 핵심 모델(신규 개발) + 2개 보유 검증 기술(통합 고도화)** 로 구성된다 (사업계획서 p.30). 과제 전체 구성은 "다항목 센서(8개) + 4가지 핵심 AI모델" 융합 구조로 규정된다 (사업계획서 p.23).

### 3.2 모델 일람표

| 구분 | 모델(역할명) | 핵심 알고리즘 | 주요 역할 | 대표 성능목표 | 출처 |
|------|--------------|---------------|-----------|----------------|------|
| 신규 개발 ① | 이상 배출 탐지 | AutoEncoder (비지도 학습) | 다변량 수질·설비 데이터 기반 복합 이상 패턴 자동 탐지 및 사전경보 | 이상 탐지 정확도 ≥90%, 오탐지율 <10% | 사업계획서 p.27, p.30, p.64 |
| 신규 개발 ② | 수질 변화 예측(간접 추정) | LSTM + Attention | 오염도 1~6시간 경향 추정 및 배출 초과 사전경보 | MAE<15%, R²>0.75, 경향성 일치율 ≥90% ⚠ | 사업계획서 p.27, p.30, p.64 |
| 신규 개발 ③ | 설비 이상 예측·분석 | RandomForest | 펌프·폭기장치 고장 사전 예측(비선형 관계 학습) | 설비 고장 예측 정확도 ≥85% | 사업계획서 p.27, p.30, p.64 |
| 신규 개발 ④ | 설비 수명주기 최적화 | XMARL-PPO (강화학습) | 설비 운전 조건 최적화, 에너지 효율 향상, 수명 연장 | 에너지 절감 ≥10%, 설비 수명 증가 ≥15% ⚠, 총 운영비 절감 ≥12% | 사업계획서 p.27, p.31, p.64 |
| 보유 검증 ⑤ | 수질 오염도 추정 | 앙상블 AI (GLM+GBM+DRF+XGBoost) | LSTM 모델과 결합(시계열 추정 + 정량 추정) | 고도화 목표 R²>0.9 | 사업계획서 p.27, p.31 |
| 보유 검증 ⑥ | 약품 투입량 최적화 | 지도학습 + 최적화 + 강화학습 | XMARL-PPO와 통합(설비 최적화 + 약품 최적화) | 현재 검증 수준 약품비 20~30% 절감 | 사업계획서 p.27, p.31 |

#### 3.2.1 모델별 선행 연구 근거

| 모델 | 선행 연구 근거(원문) | 출처 |
|------|----------------------|------|
| AutoEncoder | 환경부 R&D — 다변량 수질 데이터 이상 탐지 기법 적용 사례 / "다변량 수질 데이터 복합 이상 패턴 탐지" | 사업계획서 p.27, p.64 |
| LSTM(+Attention) | 시계열 데이터 분석(LSTM 계열) 적용 연구 다수 / "시계열 데이터 분석에 유리한 LSTM" | 사업계획서 p.27, p.64 |
| RandomForest | PHM(예지보전) 및 센서 기반 / 설비 예지보전(PHM) 연구 (정확도 80~90%) | 사업계획서 p.27, p.64 |
| XMARL-PPO | 강화학습 기반 공정 최적화 연구 및 고려대학교 XMARL-PPO 알고리즘 / 강화학습 기반 공정 최적화 및 에너지 절감 연구 증가 추세 | 사업계획서 p.27, p.64 |

> 사업계획서 p.27의 RandomForest 근거 문장은 "PHM(예지보전) 및 센서 기반"에서 서술이 끊겨 있다. 원문 상태 그대로 옮겼다.

### 3.3 모델 간 위계와 상호 참조 관계

| 모델 | 원문상 위상 | 다른 모델과의 관계 | 출처 |
|------|-------------|--------------------|------|
| LSTM | Core Prediction Model(중심 판단 모델) | 전체 AI 시스템의 중심 판단 모델로서 타 모델의 입력 기준 및 의사결정 기준 제공 | 사업계획서 p.65 |
| AutoEncoder | 이상 탐지 | LSTM 예측 모델 입력 데이터의 품질 필터링(이상값 제거) 역할 수행 | 사업계획서 p.64 |
| RandomForest | 설비 분석 | LSTM 모델의 입력 변수 중요도 및 설명력 보강 | 사업계획서 p.66 |
| XMARL-PPO | Decision Optimization Layer(의사결정 최적화 계층) | 입력에 LSTM 예측 결과(DO, TN, TP 등) 포함 | 사업계획서 p.66 |

발표자료는 통합 AI 구조를 "AutoEncoder + LSTM + Soft Sensing"으로, 시스템 아키텍처를 "Edge-NPU + Cloud-GPU 기반 Hybrid AI 구조"로 규정한다 (발표자료 p.21).

### 3.5 실시간 분석 파이프라인 (5단계)

| 단계 | 내용 | 출처 |
|------|------|------|
| Step1 | 다항목 수질센서를 통해 pH, DO, EC, 탁도, 수온, TOC, NO3-N 등 주요 수질 항목을 1분 단위로 주기적 측정 | 사업계획서 p.68 |
| Step2 | 엣지 컴퓨팅 장치(ECP)로 데이터 수집, 노이즈 제거 및 결측치 보정 등 전처리 수행 | 사업계획서 p.68 |

| Step5 | 설정된 임계값 초과 시 SMS, 이메일, 모바일 푸시 등으로 자동 알람 발송 | 사업계획서 p.68 |

> ⚠ 모순 — 데이터 수집 주기: Step1은 "1분 단위"(사업계획서 p.68), ECP 사양은 "1분~10분(설정 가능)"(사업계획서 p.30), ECP 주요 기능은 "1분~10분(설정 가능, 기본 10분)"(사업계획서 p.58), 센서 계층은 "1~10분 단위"(사업계획서 p.48), 발표자료는 "1~10분"(발표자료 p.15, p.21)이다. 여기에 더해 순차 측정 제어 알고리즘 성능 항목은 "측정 주기 10분 간격(설정 가능: **1분~60분**)"으로 설정 상한이 다르다(사업계획서 p.56). 상세는 [source-inconsistencies.md](../requirements/source-inconsistencies.md) 참조.

## 4. AutoEncoder 기반 이상 배출 탐지

### 4.1 입력

| 구분 | 입력 항목 | 출처 |
|------|-----------|------|
| 수질·설비 통합 데이터 | pH, DO, EC, 탁도, 수온, 색도, TOC, NO3-N, 전류, 전력, 유량 등 | 사업계획서 p.64 |
| 입력(개발 목표 기재) | pH, EC, 탁도, DO, 수온, 색도, NO3-N, TOC, 전류, 전력, 유량 (11개) | 사업계획서 p.30 |
| 입력(성능지표 종합표 기재) | pH, EC, 탁도, DO, 수온, 색도, 전류, 전력 (8개, 다변량 시계열) ⚠ | 사업계획서 p.31 |
| 단기 시계열 | 과거 1시간 | 사업계획서 p.64 |
| 시계열(발표자료) | 1~10분 단위, 24~72시간 이상 축적 ⚠ | 발표자료 p.15 |
| 수질(발표자료) | pH, DO, EC, 탁도, 수온, TOC, NO3-N, 색도 등 | 발표자료 p.15 |
| 설비(발표자료) | 유량, 전력, 전류, 약품 주입량 등 | 발표자료 p.15 |
| 운영(발표자료) | 설비 가동 이력, 알람 이력, 방류 운전 조건 | 발표자료 p.15 |

> ⚠ 모순 — 입력 변수 집합: p.30(11개)·p.64(11개+등)와 p.31 종합표(8개, NO3-N·TOC·유량 제외)가 다르다. 시계열 입력 구간도 p.64는 "과거 1시간", 발표자료 p.15는 "24~72시간 이상 축적"으로 다르다. 상세는 [source-inconsistencies.md](../requirements/source-inconsistencies.md) 참조.

### 4.2 처리 구조

| # | 처리 내용 | 출처 |
|---|-----------|------|
| 1 | 비지도 학습 기반 정상 패턴 분포(latent space) 학습 | 사업계획서 p.64 |
| 2 | 입력 데이터 재구성 과정에서 발생하는 Reconstruction Error를 이상 지표로 활용 | 사업계획서 p.64 |
| 3 | 다변량 상호작용 패턴을 잠재공간(latent representation)에서 통합 학습 | 사업계획서 p.64 |
| 4 | 고정 임계치 기반이 아닌 정상 패턴 기반 AI 분석 구조로 판단 기준 전환 | 발표자료 p.15 |

발표자료는 처리 절차를 6단계로 명시한다: ① 정상데이터 기반 패턴학습 → ② Encoder 기반 특징 압축 → ③ Decoder 기반 입력 데이터 복원 → ④ Reconstruction Error 계산 → ⑤ 이상점수 기반 이벤트 판단 → ⑥ 운영패턴 기반 최적화 분석 (발표자료 p.15).

학습 데이터는 "56개소 × 3년 데이터에서 학습한 정상 패턴 기반"으로 기재된다 (사업계획서 p.34, 발표자료 p.32).

### 5.1 위상

### 5.2 입력

| 구분 | 내용 | 출처 |

### 5.3 처리 구조

| # | 처리 내용 | 출처 |
|---|-----------|------|
| 1 | LSTM(Long Short-Term Memory) 기반 시계열 학습 | 사업계획서 p.65 |

| 3 | Attention 메커니즘을 통해 주요 시점(Time-step importance) 가중치 적용 | 사업계획서 p.65 |

> "고가 분석기 대체를 위한 경제적 TOC 추정" 기능은 기술적 역할로만 기술되고, 출력 규격(값 범위·형식)은 **원문 없음**이다.

### 6.6 발표자료의 Soft Sensing 역할 배정 (RandomForest / XGBoost)

발표자료는 RandomForest 계열 알고리즘을 설비 예지보전과 별개로 **Soft Sensing(TOC·TN·TP 간접 추정)** 에도 배정한다 (발표자료 p.17, p.21, p.48). 발표자료 p.48(위탁기관 핵심 AI 개발역량)도 "RF/XGBoost 기반 경향성 분류 및 Soft sensing"으로 동일하게 배정한다.

| 항목 | 내용 | 출처 |
|------|------|------|
| 대상 항목 | TOC, TN, TP (직접 수치 예측이 어려운 항목) | 발표자료 p.17 |
| 사용 알고리즘 | Random Forest / XGBoost | 발표자료 p.17 |
| 학습 방식 | 수질+설비+시계열 데이터 통합, 변수 간 비선형 관계(Non-linear Correlation) 학습 | 발표자료 p.17 |
| 처리 절차 | ① 다변량 데이터(수질+설비+시계열) → ② Feature Engineering(통계/시간/주파수 특성추출) → ③ AI 모델학습(Random Forest/XGBoost) → ④ AI 추정결과-실측데이터 비교검증 → ⑤ 실시간 데이터 입력 시 경향성 업데이트 | 발표자료 p.17 |
| 출력 — 경향성 3분류 | TOC(유기물) / TN(총질소) / TP(총인) : 상승 / 유지 / 하락 ⚠ | 발표자료 p.17 |
| 출력 — 오염도 증가 가능성 사전 판단 등급 | 정상 / 주의 / 위험 | 발표자료 p.17 |
| 출력 — 기타 | 경향성 기반 알람 및 대응 가이드 제공, 공정 운영 및 약품 투입 최적화 지원 | 발표자료 p.17 |
| 검증 방법 | 대표 실증사업장 1개소에 TN/TP 분석기 설치 기반 AI 추정 결과 비교 검증 수행 | 발표자료 p.17 |
| 강점 | 실시간 오염도 확인(기존 분석기 대비 시간 지연 제거), 시약·소모품 없는 저비용 운영 구조 | 발표자료 p.17 |

> ⚠ 모순 — 역할 배정: 사업계획서는 주로 오염도 추정을 LSTM(경향)과 앙상블 AI(정량)에 배정하고 RandomForest는 설비 예지보전에 배정하지만(p.27, p.30, p.64), **같은 사업계획서 p.54는 "RandomForest: 비선형 관계 학습 및 오염도 추정"으로 배정**하고 p.66은 "경제적 TOC 추정 기능"을 부여한다. 발표자료(p.17, p.21, p.48)도 RandomForest/XGBoost를 TOC·TN·TP 경향성 추정(Soft Sensing)에 배정한다. 즉 사업계획서 내부에서도 배정이 갈린다. 경향성 분류 표현도 "상승/하강/안정"(사업계획서 p.25, p.65)과 "상승/유지/하락"(발표자료 p.17)으로 다르다. 상세는 [source-inconsistencies.md](../requirements/source-inconsistencies.md) 참조.

#### 8.1.1 기반이 되는 TN·TP 스마트 센서 개발 실적

#### 8.1.2 TN·TP 간접 추정의 기술적 도전과제

TN(Total Nitrogen)·TP(Total Phosphorus)는 단일 센서로 직접 측정이 불가능한 항목으로 본 과제의 핵심 기술 도전과제로 규정된다 (사업계획서 p.25).

| 항목 | 원문 내용 | 출처 |
|------|-----------|------|
| TN의 센서 상관성 한계 | EC와 일부 상관성이 존재하나 질산성 질소 기여도에 따라 변동 | 사업계획서 p.25 |
| TP의 센서 상관성 한계 | 탁도와 일부 상관성이 존재하나 입자성 인 기여도에 따라 변동 | 사업계획서 p.25 |
| 구조 | 단순 선형 관계가 아닌 공정 조건에 따른 비선형·조건부 상관성 구조 | 사업계획서 p.25 |
| TN의 공정 영향 | 질산화·탈질 반응에 따라 변동(DO, pH, 온도, 미생물 활성도 영향) | 사업계획서 p.25 |
| TP의 공정 영향 | 생물학적 인 제거 효율에 따라 변동(혐기/호기 조건, 미생물 군집 영향) | 사업계획서 p.25 |
| 접근 결론 | 단일 시점 값 기반 추정 한계 → 시간 흐름에 따른 변화 패턴 분석 필수, 시계열 기반 접근 필요 | 사업계획서 p.25 |

| 항목 | 내용 | 출처 |

| 실증 | 물기술 디지털화 사업 2022-2023 실증 | 사업계획서 p.27, p.31 |

## 10. 설명가능 AI(XAI)

### 10.1 적용 원칙

XAI(설명 가능한 AI) 기법은 **필수 적용 요소**로 규정된다 — "SHAP(SHapley Additive exPlanations), Attribution 등" (사업계획서 p.60). 적용 목적은 "운영자가 공정 성능 예측 결과에 대해 이해하고 신뢰성을 높일 수 있도록" 하는 것이며(사업계획서 p.59), 사용자 기능 관점의 목적은 "운영자 신뢰도 향상"으로 기술된다 (사업계획서 p.32).

### 10.2 기법별 적용 대상과 산출물

| XAI 기법 | 적용 대상 | 산출물 | 출처 |
|----------|-----------|--------|------|
| SHAP | 시스템 전반(의사결정 근거) | SHAP값 기반 의사결정 근거 제시 | 사업계획서 p.32, p.60 |
| Attention | LSTM | 주요 영향 인자(수질 및 설비 변수)의 기여도 도출 / Attention 기반 주요 영향 인자 시각화 | 사업계획서 p.26, p.32 |
| Feature Attribution | AutoEncoder | 주요 기여 변수 | 사업계획서 p.64 |
| Feature Importance | RandomForest | 주요 영향 변수 도출 / 주요 영향 인자 식별 | 사업계획서 p.43, p.61, p.66 |
| XAI 적용(명시) | XMARL-PPO | 설비 수명주기 고려 최적화, XAI 적용 | 사업계획서 p.61 |
| 추정 근거 설명 | 오염도 간접 추정 그래프 | 추정 근거 설명(주요 영향 인자) | 사업계획서 p.32 |
