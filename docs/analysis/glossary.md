## 2. 사용 방법

이 사전은 **기반 문서 두 건의 원문에 실제로 등장하는 용어만** 수록한다. 뜻풀이는 **원문이 서술한 범위 안에서만** 적으며, 업계 통용 정의·일반론으로 빈칸을 메우지 않는다.

| 규칙 | 내용 |
|------|------|
| 수록 범위 | 원문에 등장하는 용어만. 원문에 없는 용어는 추가하지 않는다 |
| 뜻풀이 범위 | 원문이 서술한 범위 안에서만 기술. 원문이 정의하지 않은 개념은 확장 설명하지 않는다 |
| 원어(Full form) | 원문이 풀어 쓴 경우에만 기재. 원문에 풀이가 없으면 `[TBD]`로 표기하며, 일반 통용 원어를 추정해 채우지 않는다 |
| 출처 표기 | `(사업계획서 p.30)` = HSKorea_AI_Application_Proposal.pdf, `(발표자료 p.15)` = AIoT_Emission_Control_System.pdf |
| 페이지 기준 | **PDF 파일 페이지 번호**(추출 파일 `--- pNN ---` 마커) 기준이며, 원본 문서 하단 인쇄 쪽번호와는 다르다 |
| 수치 | 원문 그대로 옮긴다. 반올림·단위 환산·보정을 하지 않는다 |
| 표기 원형 | 원문 오탈자·비관용 표기는 원문대로 옮기고 §8에 별도 기록한다 |
| 값 충돌 | 원문끼리 값이 다르면 둘 다 적고 `⚠ 모순`으로 표기한다(§8, [source-inconsistencies.md](../requirements/source-inconsistencies.md) 참조) |

## 8. 표기 흔들림

같은 대상을 원문에서 다르게 적은 사례다. **어느 쪽이 옳은지 임의로 결정하지 않고 원문 표기를 모두 보존한다.** 값이 서로 어긋나는 항목은 `⚠ 모순`으로 표시했으며, 상세 대조는 [source-inconsistencies.md](../requirements/source-inconsistencies.md)를 참조한다.

### 8.1 명칭·약어 표기
