### 11.4 원문에 없는 항목 (개발 착수 전 확정 필요)

| # | 항목 | 상태 |
|---|------|------|
| 1 | 역할별 **세부 기능 단위** 권한 매트릭스 | 원문은 3역할(관리자=모든 기능, 운영자=모니터링·알람 확인, 게스트=조회만)까지만 규정(사업계획서 p.69). 어느 화면·어느 조작이 각 역할에 허용되는지는 원문 없음 |

| 7 | 시스템 가동률·고객 유지율의 측정 기간·집계 주기 | 원문 없음 (사업계획서 p.119) |
